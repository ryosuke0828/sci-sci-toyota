# データ

| 場所 | 内容 | 扱い |
|---|---|---|
| `cache/` | OpenAlex API応答の固定キャッシュ | 再現実験の入力。直接編集しない |
| `derived/` | ノートブックが出力した処理済みCSVと実行メタデータ | 再生成可能な成果物。報告書が参照するものは保持する |

`derived/access_check/` には、学術データベースへの 1 DOI の到達性検査と、大阪大学学外アクセス入口の認証前リダイレクト検査で抽出した最小限のメタデータと HTTP 状態を保存する。API キー、個人 ID、パスワード、Cookie、API応答全文、リダイレクトURLのクエリ文字列は保存しない。

`cache/` の応答には取得時点のAPI仕様とデータ状態が反映される。ライブAPIを再照会した結果で上書きせず、別名のキャッシュとして保存する。
