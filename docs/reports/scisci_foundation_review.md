## 1. SciSciNet とは何か

Microsoft Academic Graph（MAG、2021年12月の最終版）を土台に、
研究費・特許・臨床試験・報道・Twitter などの外部データを紐づけ、
さらに科学計量の主要指標を事前計算して公開したデータセット。

- 論文 1億3,400万件（MAG 由来）
- novelty / conventionality が付いているのは **44,143,650件**（1950〜2021年の journal paper）
- disruption が付いているのは 48,581,274件（前方・後方引用が1件以上ある論文）
- sleeping beauty 係数が付いているのは 52,699,363件
- コード・データとも公開（データは CC-BY-4.0）

指標は「網羅的なものではなく、コミュニティが指標を足していくための例として提供する」と
Usage Notes に明記されている。つまり**この論文は指標の提案ではなく、実装の参照点**である。

## 2. novelty / conventionality の実装（確定した仕様）

出典は Uzzi et al. 2013（本文の参照番号47）。SciSciNet はそれを MAG 上で再実装している。

### 2-1. 帰無モデル

引用エッジ（引用元, 引用先）を **(引用元の出版年, 引用先の出版年) の組**で層に分け、
層ごとに引用先だけを入れ替える。これを独立に **10回**行い、10本のランダム化ネットワークを作る。

コード（`MAG-Atyp-Comb-1990-2000.ipynb` セル4・8）:

```python
D[(Citing_Year, Cited_Year)] = list(zip(Citing, Cited))   # 層の作り方
...
origin = [i[0] for i in v]; temp = [i[1] for i in v]
for epoch in range(10):
    random.shuffle(temp)          # 引用先だけを層内で入れ替える
    for i in range(cur_len):
        Ref_List[epoch][origin[i]].append(temp[i])
```

これで「各論文が各年から引く本数」と「各ジャーナル年の被引用数」が保存される。
本文の "shuffle the reference records within the citing-cited year group" がこれにあたる。

### 2-2. ジャーナル対の数え方（重要）

各論文について、参考文献の**すべての組**を列挙し、その掲載誌の対の出現回数を足す。

```python
for i in range(cur_len):
    for j in range(i):
        cal_J(v[i], v[j], k)      # 参照の全ペアを回す

def cal_J(P_i, P_j, k):
    J_i, J_j = JID[P_i], JID[P_j]
    if J_i > J_j: J_i, J_j = J_j, J_i
    Cur_Dict[(J_i, J_j)] += 1      # 出現回数をそのまま足す
    Paper_pair[k].add((J_i, J_j))  # 論文側は集合（重複を落とす）
```

ここから読み取れる仕様は2つ。

1. **コーパス側の計数は出現回数**である。ある論文が誌Aから3本・誌Bから2本引いていれば、
   対(A,B)に **6** を足す。「両方を引いている論文の数」（＝1）ではない。
2. **同一誌どうしの対 (A, A) も数える。** `J_i > J_j` の比較なので等しいときは入れ替わらず、
   (A,A) がそのまま計上される。誌Aから2本引いていれば対(A,A)が1つできる。
   同一誌の対はふつう非常に「定石どおり」側になるので、median を押し上げる。

論文単位の集約に使うのは `Paper_pair[k]`（**集合**）なので、
1論文の中で同じ対が何回出ても z は1回だけ数える。
**コーパス側は重み付き、論文側は重複なし**という非対称になっている。

### 2-3. z と論文単位の集約

```python
mean = np.mean(tmp_Z); std = np.std(tmp_Z)   # ddof=0（母標準偏差）
if std != 0.0:
    Z_for_year[k2] = (obs - mean) / std       # std=0 の対は z を付けない＝除外
...
MAG_Z_median_list.append([k, np.quantile(Z_for_k, 0.5), len(Z_for_k)])
MAG_Z_10_pct_list.append([k, np.quantile(Z_for_k, 0.1), len(Z_for_k)])
```

- 標準偏差は `np.std`、すなわち **ddof=0**
- ランダム化で一度も出なかった対（std=0）は **z を付けずに落とす**。件数は `std_cnt` として数えている
- 論文ごとに、その論文が持つ対の z の **中央値** = conventionality、**10パーセンタイル** = tail novelty
- 有効な対の数 `Valid_Pairs` を列として残している

### 2-4. 対象の絞り込み

- コーパス（焦点論文）は `DocType == 'Journal'` の論文のみ
- 引用先も、掲載誌ID（JID）を持つもののみが対に寄与する
- **参考文献が1000本を超える論文は計算対象から外す**（`if cur_len > 1000: continue`）

## 3. 我々の実装との食い違い（5点）

| # | 論点 | SciSciNet | `src/novelty_uzzi.py`（現状） | 影響 |
|---|---|---|---|---|
| 1 | コーパス側の対の計数 | 参照の全ペアを列挙し**出現回数**を足す | 二値化して「**両方を引いた論文数**」を数える | **大**。観測値も期待値も別物になる |
| 2 | 同一誌どうしの対 (A,A) | **数える** | `j1 < j2` で**除外** | **大**。最も定石側の対が丸ごと抜け、median が下がる |
| 3 | 標準偏差 | `np.std`（ddof=0） | `ddof=1` | 小。|z| が一律 √(10/9)=1.054 倍ずれる |
| 4 | 参考文献1000本超 | 除外 | 除外しない | 我々のデータには該当0件（最大454本）。実害なし |
| 5 | 焦点論文の範囲 | `DocType == 'Journal'` | コーパスは `type='article'` だが、**焦点論文には型の制限がない** | 中。我々の790件には conference-paper が182件あり、扱いが不整合 |

1と2は、値の定義そのものが違う。**現在の718件の値は Uzzi / SciSciNet の定義ではない。**

なお、層の取り方（引用元年×引用先年）とランダム化回数（10回）、
std=0 の対を落とす扱い、median と10パーセンタイルの取り方は一致している。
帰無モデルの骨格は合っていて、数え方だけが違う。

## 4. disruption の定義（段階3-2で使う）

ある論文 p の後続引用を3種類に分ける。

- n_i … p だけを引き、p の参考文献は引かない後続論文の数
- n_j … p と p の参考文献の両方を引く後続論文の数
- n_k … p の参考文献だけを引き、p は引かない後続論文の数

D = (n_i − n_j) / (n_i + n_j + n_k)

前方・後方引用が1件以上ある論文について計算する。
n_k を求めるには「p の参考文献を引いている論文」が要るので、
**引用の向きを逆にした表（段階0-3）が前提**になる。

出典は本文の参照番号20・51（Funk & Owen-Smith 2017、Wu/Wang/Evans 2019）。
これらは未読なので、CD index の変種（CD5 など時間窓を切るもの）の扱いは段階2で確認する。
公開コードには `MAG-Disruption.ipynb` と `MAG-Disruption-CD5.ipynb` の2本があり、
時間窓ありの版も別に計算されている。

## 5. SciSciNet 自身による Uzzi の再現（Fig. 7d）

「5%ヒット論文になる確率を、novelty と conventionality の2×2で条件づけたもの。
**1950〜2000年の journal article 全件**が対象」。

読み取れること。

- 成果側の指標は **上位5%に入るか（ヒット論文）** であり、被引用数の中央値ではない
- 対象を1950〜2000年に切っている。被引用が貯まりきった論文だけを使うため
- この図では**参考文献数を統制していない**

我々が 2026-09-08 に「参考文献数の交絡で関係が消える」と報告した件は、
SciSciNet のこの図でも統制されていない論点である。批判として成立しうるが、
段階2で先行研究の批判文献を確認してから位置づけるべきで、
現時点で「再現しなかった」と結論するのは早い。加えて、上記の食い違い1・2により
そもそも我々の値が同じ定義になっていないので、あの比較自体をやり直す必要がある。
