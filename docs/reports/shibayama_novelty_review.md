- **AGENTS.md と CLAUDE.md**: AI エージェントが作業の前に読む指示書。併合すると、伊倉の AI も林さんの AI も同じものを読む。

**なぜ困るか。** 伊倉側のリポジトリはこの決まりに沿って作ってあります。決まりが消えたまま併合すると、伊倉側の作りが決まりと合わなくなります。

**やってほしいこと。** 決まりを、解析名を入れた形で戻してください。林さんの出力にも当てはまるものがあるかもしれません。たとえば工程4の「計算し直して一致した」という記録（build_title_distance_pairs_summary.json）は、後の工程も README も使っていなければ当てはまります。README の数字の出どころになっているファイルは、今のままで構いません。

### 3. 論文の表に、取り方の記録が無い列が2つある

**何が起きているか。** papers.csv の末尾の2列（被引用が上位10%・上位1%に入るか）は、10月1日に OpenAlex から取って、写した表に足したものです。この2列を取ってくるプログラムが、リポジトリにありません。

**なぜ困るか。** 取り方がプログラムとして残っていないと、ほかの人は同じ値を作れず、正しく取れているかを確かめることもできません。OpenAlex の値は日々更新されるので、取り直すと値が変わることもあります。また、2で写しを消すとこの2列も一緒に消えて、工程9が動かなくなります。

**やってほしいこと。** OpenAlex から取ってくる工程を1つ足してください。OpenAlex からの返答はそのまま data/cache/ に保存してコミットし、2回目からは保存したものを使う形にします。こうすると、何度流しても同じ値になります。10月1日に取ったときの返答が手元に残っていれば、それを保存ファイルにすると今の結果のまま保てます。残っていなければ取り直しになり、工程9の結果が少し変わるかもしれません。

```
data/raw/papers.csv の末尾2列（is_in_top_10_percent、is_in_top_1_percent）を、プログラムで取得する工程に置き換えてください。
- 新しいスクリプト src/shibayama_novelty/fetch_citation_percentiles.py を作る。data/raw/papers.csv の work_id の論文について、OpenAlex Works API の citation_normalized_percentile を取得する。1回の問い合わせで50件ずつまとめて取る。
- OpenAlex の返答はそのまま data/cache/ に保存し、保存ファイルがあれば問い合わせずにそれを使う。保存ファイルはコミットする。連絡先のメールアドレスは環境変数から読み、コードに書かない。変数の名前は .env.example に書く。
- 出力は data/derived/shibayama_novelty/ の下に、paper_uid と2列だけの表として書く。取得日も記録する。
- validate_novelty_citations.py は、2列をこの出力から読むように変える。
- data/raw/papers.csv から2列を消す。
- 新しい工程は今の工程9の直前に入れ、今の工程9を工程10にする。README の工程の表、reproduce_shibayama_novelty.ipynb、data/README.md を合わせて直す。
- 再現の確認のノートブックを流す。工程10（今の工程9）の結果が変わったら、変わった数字と理由を私に報告してから README を直す。
```

**なぜ困るか。** 研究の関係者に大阪大学以外の人が入ると、規約違反になります。zip やファイルを人に渡すときも同じです。

**やってほしいこと。** 注意書きに、Scopus のデータを含むことと、見せてよいのは大阪大学の構成員だけであることを書いてください。併合したあとは、伊倉側の README の冒頭に同じ注意書きがあるので、そちらに一本化します。なお林さんの計算は Scopus の列を使っていないので、2で写しを消せば、林さんの区画から Scopus のデータは無くなります。

```
README.md 冒頭の「共有の範囲」の注意書きを直してください。次の3点を書く。
- data/raw/authorships.csv に、Scopus から取った列（affil_scopus、scopus_author_id）が含まれる。
- Scopus の利用規約により、見せてよいのは契約している大阪大学の構成員だけである。
```

**やってほしいこと。** 次の4つをお願いします。
