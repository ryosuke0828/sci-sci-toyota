## 1. これは何の論文か

SciSciNet と同じ Dashun Wang らのグループが作った、**科学計量の研究を LLM に手伝わせる
マルチエージェント・システム**。データセットでも指標でもなく、道具である。

ChatGPT のような対話画面から研究上の問いを投げると、システムが手順に分解して自分で
データを引き、統計処理し、図を作って返す。裏側は Anthropic Claude の API を呼んでいる
（本文に "currently Anthropic Claude" と明記されている）。

## 2. 構成

一つの司令塔と四つの専門役に分かれている。

- **ResearchManager** … 要求を受け取り、作業に分解して専門役に割り振る
- **LiteratureSpecialist** … 文献を検索して要約する
- **DatabaseSpecialist** … データベースの表を調べ、SQL を書いてデータを取り出す
- **AnalyticsSpecialist** … 統計処理と可視化。Python / R / Julia を隔離環境で実行する
- **EvaluationSpecialist** … 各段階の出来を採点し、閾値に届かなければやり直させる

専門役が作業を終えると司令塔に戻り、次の割り振りに進む。
DatabaseSpecialist の道具立ては `sql_list_table`（表の一覧）、`sql_get_schema`（列の定義）、
`sql_query`（実行）、`name_search`（機関名や分野名の表記ゆれを埋め込み類似で寄せる）の4つ。

最後の `name_search` は、我々が所属文字列の正規化（段階0-4）で手作業に近い形でやったことと
同じ問題に対する解であり、参考になる。

## 3. 評価の結果と、その信頼性

事例研究2件（アイビーリーグ8大学の共著ネットワーク、SciSciNet の図の再現）を示したうえで、
簡単な比較実験を行っている。

- 比較相手は研究者3名（博士前・博士・博士研究員）。**全員が汎用のLLMを使ってよい条件**
  （Claude 3.5、GPT-4o、ChatGPT-o1 を実際に使用）。したがって「人間 対 AI」ではなく
  「汎用LLMを使う人間 対 専用システム」の比較である
- 所要時間は**人間の約10%**
- 品質は博士研究員3名が5段階で採点し、5観点すべてで SciSciGPT が上回った
- EvaluationSpecialist 自身の妥当性も専門家3名が採点。ToolEval 4.98、TaskEval 5.00 に対し
  **VisualEval は 4.17 と低い**。図の良し悪しの判定は、いまのLLMの画像理解の弱さが出ている

**著者ら自身が "our evaluations in this paper are exploratory by nature" と書いている。**
被験者3名、評価者3名で、統計的な主張はしていない。時間10%という数字を
一般的な結論として引用するのは適切でない。

## 4. LLMエージェントの成熟度モデル（4段階）

この論文のもう一つの主張。AIを研究の共同作業者として使う際の到達度を4段階に整理している。

1. **機能** … 道具を与えて文章生成の外に出す（知識・データ・手法）
2. **手順の統括** … 計画と、自己評価による反省。SciSciGPT では司令塔と EvaluationSpecialist
3. **記憶** … 過去のやりとりを保持し、文脈に応じて適応する
4. **人間との協働** … 対話で研究を進める。人間を道具として呼び出すことも含む

この枠組み自体は、我々の作業の進め方を点検する物差しとして使える。
特に第2段階の「自己評価」は、今回こちらが実装を検算せずに先へ進んだ失敗と直接関係する。

段階2-1 の設計を見直す。引用を辿る方法と、このコーパスから引く方法の両方を使い、
互いの取りこぼしを確認するのが妥当と考える。ただし採否は段階2-4 で決める。

## 6. 先生への「AIの使い方の write-up」への材料

この論文は、まさにその題材である。使えそうな論点を挙げておく。

- 汎用のLLMを直接使うのと、領域専用に道具とデータを与えたシステムを使うのとで差が出ること
- 自己評価の役を別に立てる設計。ただし図の評価は当てにならない（VisualEval 4.17）
- 著者らが評価を「探索的」と限定していること。効果の主張には慎重であるべきこと
- 我々自身の失敗（実装を一次資料と突き合わせずに進めた）が、成熟度モデルの第2段階
  「反省の仕組み」の欠如としてきれいに説明できること

これは write-up を書く段になって使う。いまは材料として記録するにとどめる。
