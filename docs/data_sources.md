# 使用しているデータベースとその使い分け

2026年8月17日　伊倉涼介

論文と研究者のデータベースを構築するために、四つの外部データベースを役割ごとに使い分けている。本書は、それぞれに何をさせているか、そしてなぜその分担になったかを記す。実装の詳細には立ち入らない。

## 使い分けを貫く判断

四つの分担は、一つの判断から導かれている。**著者を名前で検索するより、論文から引く方が安全である**という判断である。

著者名で検索すると同姓同名が必ず混ざる。姓と名前の頭文字しか記録されていない著者も多く、名前だけを手がかりにする限り、この曖昧さは原理的に解消できない。一方、論文は DOI（論文に振られる国際的な識別番号）によって一意に定まる。どの論文かが既に確定していれば、そこから著者名や所属を取り出しても人物の取り違えは起こらない。「この人物は誰か」という難しい問いを、「この論文の著者は誰か」という確実に答えられる問いに置き換えているわけである。以下に述べる四つの役割分担は、いずれもこの置き換えを守るための配置になっている。

| データベース | 費用 | 何を単位に引くか | 主な役割 |
|---|---|---|---|
| OpenAlex | 無料 | 論文 | 論文の同定、被引用・参考文献・分野分類の取得 |
| Crossref | 無料（上限なし） | 論文 | 著者名と ORCID の補完 |
| Scopus | 大阪大学の契約 | 論文 | 著者の所属の取得 |
| Web of Science | 大阪大学の契約 | 機関 | 機関名による論文の掘り起こし |

## 1. OpenAlex — 論文を同定し、指標計算の土台を作る

OpenAlex は、集めた論文を学術界共通の座標に載せる役割を担う。公式サイトから集めた919件のうち852件をこのデータベース上の論文に対応づけ、被引用24,786件、参考文献27,052件、および分野分類を取得した。指標計算に必要なデータはここから得られる。

ただし、**このデータベースが著者に振っている識別番号は使わない**。同姓同名の別人が一つの番号にまとめられているためである。たとえば「S. Nakamura」という著者は、この併合の結果として研究歴が74年に及ぶ。受領した著者リスト（9,429名分）も同じデータベースに由来しており、外部で裏付けの取れた割合は30.0〜62.9%にとどまった。最も低い群の30.0%はこの併合によるものだが、48.6%だった群は原因が異なり、所属の誤帰属によるものである。いずれにせよ、著者の同定をこのデータベースに委ねることはできない。

費用と分量の制約は問題にならない。無料の範囲では1日に1,000回しか問い合わせできないが、1回で50件をまとめて取得できるため、実質的には1日5万件である。今回の規模であれば数日に分ければ収まり、費用は発生しない。

一方、対応づけの正しさには注意が要る。DOI が完全に一致していながら、返ってくる書誌情報が誤っている例が2件見つかった。Optics Letters に掲載された論文に、1946年のスペイン語の眼科論文の書誌が紐づいていたものである。**DOI の一致は無謬ではない**。対応づけの結果を無条件に信用せず、疑わしいものは個別に確認する必要がある。

## 2. Crossref — 著者名と、信頼できる唯一の識別子を補う

Crossref は DOI を管理している団体のデータベースで、無料かつ件数の上限なく利用できる。ここには二つの役割を負わせている。

第一は著者名の補完である。AISIN IMRA 米国法人の論文313件は、**公式サイトに著者名の記載が一切なかった**。タイトルと掲載誌は載っているが、誰が書いたのかは分からない状態である。この空白を Crossref で埋めた。

第二の、そして最大の収穫が ORCID である。ORCID は研究者が自ら登録する国際的な識別番号で、383件を取得した。OpenAlex の著者識別番号も Web of Science の研究者識別番号も、実際に調べると別人を過剰に併合していた。その中で、実測してクリーンだった識別子は ORCID だけである。そこで ORCID を名寄せ（同一人物の複数表記を統合する処理）の正解ラベルに用い、名寄せがどれくらい間違えるかを測る基準とした。別人を同一人物とする誤りが4.3%、同一人物を分ける誤りが1.0%という数値は、この基準によって得られたものである。

弱点は所属情報にある。Crossref が所属を持っていたのは全体の34.5%にとどまる。所属は出版社が登録した場合にしか入らないためである。所属は別の情報源から取る必要があり、その役割を Scopus が担う。

## 3. Scopus — 論文から所属を引く

Scopus は大阪大学の契約で利用でき、著者の所属を取る役割を担う。ここに至るまでには方針の変更があり、その経緯自体が冒頭の判断の根拠になっている。

当初は Scopus 上で著者を名前で検索するつもりであった。これを二つの理由で断念した。一つは、ORCID による検索が、試した6名すべてで0件だったことである。Scopus 側に ORCID がほとんど登録されておらず、最も信頼できる識別子が検索の手がかりにならない。もう一つは、名前での検索が同姓同名を排除できないことである。「Suzuki」という姓で検索すると45,844件が該当し、この中から目的の人物を選び出す手立てがない。

そこで、**論文から所属を引く方式に切り替えた**。どの論文であるかは既に確定しているため、この方式であれば人物の取り違えが起きない。結果として、所属が分かる論文の割合は34.5%から96.1%に上がった。Scopus だけが所属を持っていた論文は394件あり、Crossref が取りこぼしていた分をここで回収した形である。

利用回数は週単位の上限が定められているが、今回の規模に対しては十分な余裕がある。所属の取得については、この方式で概ね解決したと考えてよい。

## 4. Web of Science — 機関名で論文を掘る

Web of Science も大阪大学の契約で利用できるが、他の三つとは引く単位が異なり、機関を単位に引く。理由は、このデータベースから返ってくるデータに所属の欄が含まれていないことにある。個々の論文について著者の所属を確かめる用途には使えない。

代わりに、検索の側で機関名による絞り込みが効く。これを使って833件を回収した。成果として重要なのは二点である。公式サイトに論文一覧を持たない AISIN IMRA 欧州法人の25件を埋めたこと、そして公式サイトに載っていない683件を見つけたことである。公式サイトの掲載漏れを補う手段として機能している。対象組織をどこまで広げるかの検討材料も、ここで得た。豊田工業大学6,295件、デンソー1,457件といった数字である。組織の範囲を広げる判断が下れば、同じ方法で回収できる。

用途はこの二つに限定している。パイロット検証では、著者名と機関名の組み合わせを所属の間接証拠として使えるかどうかを試した。その結果、**Scopus が見つけられなかった所属を1件も新規に発見しなかった**。そのため、所属の新規発見からは外し、機関名での網羅と、Scopus の判定の裏付けに用途を絞っている。

## まとめ

四つのデータベースは、引く単位で二つに分かれる。OpenAlex・Crossref・Scopus は論文を単位に引き、Web of Science は機関を単位に引く。**著者を単位に引くのは最後の手段である**。同姓同名の問題を避けられないためであり、Scopus での方針変更はその実例である。

著者の識別子として信頼できるのは ORCID だけであり、それも著者全体の一部にしか付いていない。ORCID を持たない著者は、名寄せに誤りが残ることを前提とし、その誤り率を実測したうえで扱っている。

費用は発生しない。OpenAlex と Crossref は無料の範囲に収まり、Scopus と Web of Science は大阪大学の契約の範囲で利用している。
