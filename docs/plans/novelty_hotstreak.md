## 決めたこと（すべて暫定・2026-08-24 時点）

| 論点 | 決定 | 理由 |
|---|---|---|
| 優先順位 | novelty（論文単位）を先行、hot streak は後段 | 論文単位は既存テーブルで着手できる。hot streak は著者キャリアの再構築が前提で準備が重い |
| 指標の入手 | すべて自前実装 | 定義を把握した状態で結果を説明できるようにするため |
| 検算 | SciSciNet の公開値との相関のみに使う | 実装バグの検出。本番の数値には使わない |
| 比較対象 | 分野×年でマッチした一般論文（基準線）＋トヨタ内部比較 | 外部の統制群は指標の正規化に使い、実質的な比較はトヨタ内部で行う |
| 対象期間 | 2000年以降（788件） | 1990年代以前62件は参照文献の登録が薄く novelty が不安定。帰無モデルの計算年数も抑えられる |
| 説明変数 | チーム規模・構成／産学連携／組織横断性／キャリア段階の4系統すべて | それぞれ独立に計測し、すべて報告する |
| 文献調査 | 網羅重視・大規模（100本超を機械収集してスクリーニング） | 抜け漏れを減らす |
| 先生への報告 | 段階3完了時に一回 | 途中報告は行わない |

## 実測した前提（2026-08-24）

### OpenAlex API は背景コーパスの取得に使えない

```
x-ratelimit-limit: 1000        1日1000リクエスト
x-ratelimit-cost-usd: 0.0001   従量課金。無料枠は1日 $0.10 分
```

数千万論文の参照文献をAPIで引くのは不可能。**スナップショット経由に切り替える。**

### スナップショットは Parquet で、必要な列だけなら約50GB

- 場所: `s3://openalex/data/parquet/`（匿名で読める）
- 版: 2026-06-26、works 510,372,821 件、全体 725.0 GB
- 列ごとの実測（`updated_date=2025-11-06/part_1068.parquet`、184 MB、146,388行 で計測）

| 列 | 圧縮後サイズ | 全体比 |
|---|---:|---:|
| `referenced_works.list.element` | 6.27 MB | 3.4% |
| `authorships.list.element.author.id` | 1.77 MB | 1.0% |
| `doi` | 1.76 MB | 1.0% |
| `id` | 1.35 MB | 0.7% |
| `authorships...institutions.list.element.id` | 0.53 MB | 0.3% |
| `primary_location.source.id` | 0.40 MB | 0.2% |
| `publication_year` | 0.17 MB | 0.1% |
| `primary_topic.field.id` | 0.09 MB | 0.05% |
| `type` / `cited_by_count` | 0.14 MB | 0.08% |
| **合計** | **12.7 MB** | **6.9%** |

725 GB × 6.9% ≒ **50 GB**。

参考: `abstract_inverted_index` だけで全体の30.1%を占める。列を絞る効果が大きい。

### 回線速度と所要時間

- 単一ストリーム: 3.6 MB/s
- 8並列: 4.8 MB/s（ここが上限らしい）
- DuckDB の列プルーニング読み出しで 905 MB分の元ファイル（4ファイル、729,516行、参照リンク 3,029,884本）を 15.1 秒

→ **50 GB のダウンロードに約3時間。** 空きディスクは 489 GB あるので問題ない。

### 置き場所

`~/scisci-data/`（Google Drive の外）。Drive 内に50GBを置くと同期が破綻し、2026-08-06 の巻き戻り事故と同種のリスクを負う。
自動取得の `~/scisci-auto/` とは別ディレクトリにする（用途が違い、`sync_auto.sh` の対象にもしない）。

### まだ測っていないこと

Uzzi 流 novelty の帰無モデルの計算コスト。主要5分野（Engineering 32.4M、Computer Science 7.2M、
Materials Science 4.5M、Physics and Astronomy 4.2M、Decision Sciences 0.9M、いずれも 1990-2026 の article）で
約49M論文あり、参照文献のジャーナル対を全列挙すると年あたり十数億行になる。

逃げ道はある。z-score が必要なのは我々の788件に現れるジャーナル対だけ（概算37万対）なので、
ランダム化コーパスを列挙する際にその対集合だけ半結合で拾えばメモリは小さく済む。
**所要時間は段階1で1年分のパイロットを回して実測する。** 想定外に重ければランダム化回数か対象年で調整する。
